# Lecture 05 · HTML Mini Project + Code Review

**Web Designing** · Module: HTML · Technoledge Eduresearch Pvt. Ltd. · Trainer: Gourav Kashiv

## Six things to remember

1. Plan pages, folders and the nav before any code.
2. Done means checked: validator, links, keyboard.
3. Find bugs with evidence, then log them.
4. Review the code, not the person.
5. Accept or reject every comment, with a reason.
6. AI reviews are suggestions. You verify.

## How to use it

1. **Download:** green **Code** button → **Download ZIP**, or `git clone https://github.com/gouravkashiv7/web-design-lec-05.git`
2. **Open** the folder in VS Code.
3. **Run** any `.html` file: right-click → **Open with Live Server**.
4. **Don't edit the originals.** Copy the `project/starter/` folder and work in your copy.

## Homework

Finish Project 1: fix accepted review comments, write `README.md`, validate every page, test with the keyboard. Full brief: [`project/project-brief.md`](project/project-brief.md).
